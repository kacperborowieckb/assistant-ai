# Personal agent foundation

Working name: assistant-ai. This is an early foundation for a self-hosted personal agent. Product apps and shared packages are not implemented yet.

Use the Node.js and pnpm versions specified in `package.json`.

```sh
pnpm install --frozen-lockfile
pnpm verify
```
